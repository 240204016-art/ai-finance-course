SDU Taxi Share — запуск на Windows без установки Python
=======================================================

1. Распакуйте архив в отдельную папку, например C:\SDUTaxiShare
   (не запускайте прямо из архива — бот хранит рядом с собой базу и настройки).

2. Дважды щёлкните SDUTaxiShare.exe.
   Если Windows покажет «Система Windows защитила ваш компьютер» —
   нажмите «Подробнее» → «Выполнить в любом случае». Это предупреждение
   появляется для любых программ без платной цифровой подписи.

3. При первом запуске бот задаст вопросы в чёрном окне:
   - Токен бота — получите у @BotFather в Telegram (/newbot).
     Вставить в окно: правый щелчок мыши.
   - Ваш Telegram ID — напишите боту @userinfobot, он пришлёт число Id.
   - Gmail для отправки кодов — можно пропустить (Enter): тогда коды
     подтверждения будут видны в этом окне. Для студентов почту нужно
     настроить: нужен «пароль приложения» Google
     (Аккаунт Google → Безопасность → Двухэтапная аутентификация →
     Пароли приложений).

4. Когда появится «Бот работает» — откройте своего бота в Telegram и
   нажмите Start.

ВАЖНО
- Бот работает, только пока открыто это окно и компьютер включён.
  Отключите спящий режим: Параметры → Система → Питание → «Переводить
  в спящий режим» → «Никогда».
- Не запускайте бота одновременно на двух компьютерах с одним токеном.
- Настройки лежат в файле .env (открывается Блокнотом), база — в папке data,
  журнал — в папке logs. Перенося бота на другой компьютер, копируйте
  всю папку целиком.
- Новая версия бота: замените только SDUTaxiShare.exe, папки data и файл .env
  оставьте — данные сохранятся.
