# Биология — ҰБТ үлгісіндегі тест

`Биология тест 2.docx` файлынан құрылған, браузерде жұмыс істейтін тест.
Сервер де, орнату да қажет емес — бір HTML файл.

**Ашу:** https://240204016-art.github.io/ai-finance-course/

## Нұсқалар

| Нұсқа | Сұрақ | Балл | Ерекшелігі |
| --- | --- | --- | --- |
| 2-тест | 40 | 50 | |
| 3-тест | 40 | 50 | |
| 4-тест | 40 | 50 | |
| 5-тест | 40 | 50 | суретті тапсырма |
| 6-тест | 40 | 50 | 5 суретті тапсырма |

Барлығы **200 сұрақ**. Басты бетте нұсқа таңдалады; әр нұсқаның өз таймері мен
жеке нәтижесі болады, жартылай тапсырылғаны сақталып, кейін жалғасады.

## Әр нұсқаның құрылымы

| Сұрақтар | Түрі | Балл |
| --- | --- | --- |
| 1–30 | Бір дұрыс жауап | 1 |
| 31–35 | Сәйкестендіру — әр жұп бөлек бағаланады | 2 |
| 36–40 | Бірнеше дұрыс жауап | 2 |

26–30 сұрақтар оқу мәтінімен (кейде суретпен) беріледі.

Бірнеше дұрыс жауапты сұрақтар ҰБТ ережесімен бағаланады: барлық дұрыс нұсқа
белгіленсе — 2 балл, дәл біреуі жетіспесе — 1 балл, одан аз, артық немесе қате
нұсқа болса — 0 балл.

## Мүмкіндіктері

- Таймер: 40 / 60 / 90 минут немесе шектеусіз
- Сұрақтар мен жауап нұсқаларын араластыру
- Емтихан және жаттығу (дұрыс жауап бірден көрінеді) режимдері
- Сұрақтар картасы, «белгілеп қою», пернетақта жылдамдатқыштары
- Аяқтағаннан кейін: балл, бөлімдер бойынша талдау, әр сұрақтың шолуы, «тек қателер» сүзгісі
- Жартылай тапсырылған тест браузерде сақталады және жалғасады

`index.html` пен `artifact.html` — құрастырылатын файлдар, оларды қолмен түзетудің

## Өзгерту

Сұрақ мәтінін, нұсқаларды немесе дұрыс жауапты `tests/` ішіндегі файлдан түзетіп:

```sh
python3 build.py
```

`build.py` құрастыру кезінде тексереді: дұрыс жауап белгіленбесе, сәйкестендіруде
жұп саны 2-ден өзге болса немесе жауап нұсқалар арасында болмаса — қатемен тоқтайды.

Беттің көрінісін не логикасын өзгерту үшін `src/page.html` файлын түзетіп, сол
команданы қайталаңыз.

### Жаңа нұсқа қосу

docx файлы дайын болса (дұрыс жауаптың **мәтіні** қалың әріппен):

```sh
python3 tools/parse_test.py <ашылған-docx-қалтасы> "7-тест" test7 assets "assets/" tests/test-7.json
python3 build.py
```

Талдағыш бір дұрыс жауапты, бірнеше жауапты және сәйкестендіру сұрақтарын, оқу
мәтіндері мен суреттерді өзі ажыратады. Тек әріп қалың болып, жауап мәтіні қалың
болмаса, ол нұсқа дұрыс жауап деп саналмайды.

### tests/*.json пішімі

```jsonc
{ "slug": "test7", "title": "7-тест",
  "questions": [
    { "n": 1, "type": "single",            // single | multi | match
      "q": "Сұрақ мәтіні",
      "options": [ { "id": "A", "text": "Нұсқа" } ],
      "answer": "A",                       // single: бір әріп
                                           // multi:  ["B","C","D"]
                                           // match:  жоқ, орнына items
      "items": [ { "text": "Липаза", "answer": "B" } ],   // тек match үшін
      "points": 1,
      "images": ["assets/test7-1.png"],                   // міндетті емес
      "context": { "title": "…", "body": "…",             // міндетті емес
                   "images": ["assets/test7-2.png"] } }
  ] }
```

## Нәтижелерді жинау және дашборд

Әдепкіде өшірулі: `config.json` ішіндегі `submitUrl` бос болса, тест бұрынғыдай
жұмыс істейді, ешқандай дерек ешқайда жіберілмейді.

Қосылғанда оқушы **email-ін растап** кіреді, тест аяқталғанда нәтижесі сіздің
Google кестеңізге түседі. `dashboard.html` сол кестені оқып талдайды.

> **Тек GitHub Pages нұсқасында жұмыс істейді.** Claude артефактісі қауіпсіздік
> саясаты бойынша сыртқа сұраныс жібере алмайды, сондықтан ол нұсқада жинау
> әрқашан өшірулі болады.

### Оқушының кіруі

1. Email жазады → оған алты саннан тұратын код келеді (15 минут жарамды)
2. Кодты енгізеді → сеанс ашылады (12 сағат, браузерде сақталады)
3. Аты-жөні мен сыныбын бір рет жазады — келесі кіруде өзі толтырылады
4. Нұсқалар ашылады

Нәтиже жіберілгенде сервер сеанс токенін тексереді, сондықтан бөтен адамның
атынан жазба жасау мүмкін емес. Кодты біреуге берудің де мәні жоқ — нәтиже
бәрібір сол email иесінің атына жазылады.

### Қайта тапсыру

Шектелмейді, бірақ есепке алынады: әр жазбада «Әрекет» бағаны болады
(1, 2, 3…), дашбордта «2-рет» деп белгіленеді, ал оқушының жеке бетінде
барлық әрекеті бөлек чиптермен көрінеді.

### Орнату

1. `tools/apps-script.gs` ішіндегі нұсқаулықты орындаңыз: кестені ашып
   Extensions → Apps Script, кодты қою, `SECRET_KEY` мен `SHEET_ID` толтыру,
   Deploy → Web app → **Anyone**.
2. Шыққан мекенжайды `config.json` ішіндегі `submitUrl` өрісіне қойыңыз.
3. `python3 build.py` жүргізіп, өзгерісті пушқа жіберіңіз.

**`config.json` ішіне `SECRET_KEY` жазбаңыз** — ол файл сайтпен бірге
жарияланады, яғни кез келген адам оқи алады.

### Кестедегі парақтар (өздері жасалады)

| Парақ | Мазмұны |
| --- | --- |
| `Нәтижелер` | Тапсырылған жұмыстар |
| `Кодтар` | Email растау кодтары мен сеанс токендері |
| `Рұқсат` | **Міндетті емес.** Бір бағанға email тізімін жазсаңыз, тек сол адамдар тест тапсыра алады. Бос болса — кез келген расталған email жарайды |

### Дашборд

`.../dashboard.html` мекенжайында ашылады, кірген кезде `SECRET_KEY` сұралады.
Бетке сілтеме қойылмаған, сондықтан оқушылар оны кездейсоқ таппайды.

Ішінде: жалпы көрсеткіштер, нұсқа мен сынып бойынша орташа нәтиже, балл
таралымы, әр сұрақтың қиындығы және тапсырғандар кестесі. **Кестедегі жолды
басқанда оқушының жеке беті ашылады**: бөлімдер бойынша балл және 40 сұрақтың
әрқайсысы — оқушының жауабы мен дұрыс жауабы қатар, «тек қателер» сүзгісімен.
Кез келген сүзгідегі деректі CSV етіп жүктеуге болады.

### Хат жіберу шегі

Растау кодтары Google арқылы кетеді: жеке Gmail аккаунтында тәулігіне
100 хат, Workspace аккаунтында 1500. Бір email үшін жаңа кодты 60 секундтан
кейін ғана сұрауға болады.

### Жиналатын деректер

Email, аты-жөні, сынып, нұсқа, әрекет нөмірі, балл, пайыз, жұмсаған уақыты,
режим, әр сұрақтың нәтижесі (`marks`: `1` толық, `h` жартылай, `0` қате,
`-` жауапсыз) және таңдаған нұсқалары (`picks`). Бәрі сіздің Google
кестеңізде — үшінші тарапқа ешнәрсе жіберілмейді.

## Бағалау

- **Бір дұрыс жауап** — 1 балл
- **Сәйкестендіру** — әр жұп бөлек, әрқайсысы 1 балл (барлығы 2)
- **Бірнеше дұрыс жауап** — ҰБТ ережесімен: барлық дұрыс нұсқа белгіленсе 2 балл,
  дәл біреуі жетіспесе 1 балл, одан аз, артық немесе қате нұсқа болса 0 балл

## Жариялау

Сайт `main` бұтағының түбірінен тікелей беріледі: **Settings → Pages → Source →
`Deploy from a branch`**, Branch `main`, папка `/ (root)`. `main`-ге әр пуштан
кейін GitHub сайтты өзі қайта құрастырады.

`.nojekyll` файлы Jekyll өңдеуін өшіреді, сондықтан `index.html` сол күйі беріледі.

`.github/workflows/build-check.yml` жариялауға қатыспайды — ол тек құрастырылған
файлдардың `tests/` ішіндегі деректермен сәйкестігін тексереді.

Жергілікті қарау үшін `index.html` файлын браузерде ашсаңыз жеткілікті —
серверсіз де жұмыс істейді.
