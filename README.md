# Биология — ҰБТ үлгісіндегі тест

`Биология тест 2.docx` файлынан құрылған, браузерде жұмыс істейтін тест.
Сервер де, орнату да қажет емес — бір HTML файл.

**Ашу:** https://240204016-art.github.io/ai-finance-course/

## Нұсқалар

| Нұсқа | Сұрақ | Балл | Ерекшелігі |
| --- | --- | --- | --- |
| 2-тест | 40 | 50 | |
| 3-тест | 40 | 50 | |
| 4-тест | 40 | 50 | |
| 5-тест | 40 | 50 | суретті тапсырма |
| 6-тест | 40 | 50 | 5 суретті тапсырма |

Барлығы **200 сұрақ**. Басты бетте нұсқа таңдалады; әр нұсқаның өз таймері мен
жеке нәтижесі болады, жартылай тапсырылғаны сақталып, кейін жалғасады.

## Әр нұсқаның құрылымы

| Сұрақтар | Түрі | Балл |
| --- | --- | --- |
| 1–30 | Бір дұрыс жауап | 1 |
| 31–35 | Сәйкестендіру — әр жұп бөлек бағаланады | 2 |
| 36–40 | Бірнеше дұрыс жауап | 2 |

26–30 сұрақтар оқу мәтінімен (кейде суретпен) беріледі.

Бірнеше дұрыс жауапты сұрақтар ҰБТ ережесімен бағаланады: барлық дұрыс нұсқа
белгіленсе — 2 балл, дәл біреуі жетіспесе — 1 балл, одан аз, артық немесе қате
нұсқа болса — 0 балл.

## Мүмкіндіктері

- Таймер: 40 / 60 / 90 минут немесе шектеусіз
- Сұрақтар мен жауап нұсқаларын араластыру
- Емтихан және жаттығу (дұрыс жауап бірден көрінеді) режимдері
- Сұрақтар картасы, «белгілеп қою», пернетақта жылдамдатқыштары
- Аяқтағаннан кейін: балл, бөлімдер бойынша талдау, әр сұрақтың шолуы, «тек қателер» сүзгісі
- Жартылай тапсырылған тест браузерде сақталады және жалғасады

## Файлдар

| Файл | Мазмұны |
| --- | --- |
| `tests/test-N.json` | Нұсқаның сұрақтары — жалғыз дереккөз |
| `assets/` | Тапсырмалардағы суреттер |
| `src/page.html` | Беттің шаблоны (мәнер, логика), деректер орны `__DATA__` |
| `build.py` | Шаблон мен деректерден екі нұсқаны құрастырады |
| `tools/` | docx файлынан `tests/*.json` жасайтын талдағыш |
| `index.html` | Толық HTML құжат — GitHub Pages жариялайтын нұсқа |
| `artifact.html` | Тек бет мазмұны — Claude артефактісі үшін |

`index.html` пен `artifact.html` — құрастырылатын файлдар, оларды қолмен түзетудің
қажеті жоқ.

## Өзгерту

Сұрақ мәтінін, нұсқаларды немесе дұрыс жауапты `tests/` ішіндегі файлдан түзетіп:

```sh
python3 build.py
```

`build.py` құрастыру кезінде тексереді: дұрыс жауап белгіленбесе, сәйкестендіруде
жұп саны 2-ден өзге болса немесе жауап нұсқалар арасында болмаса — қатемен тоқтайды.

Беттің көрінісін не логикасын өзгерту үшін `src/page.html` файлын түзетіп, сол
команданы қайталаңыз.

### Жаңа нұсқа қосу

docx файлы дайын болса (дұрыс жауаптың **мәтіні** қалың әріппен):

```sh
python3 tools/parse_test.py <ашылған-docx-қалтасы> "7-тест" test7 assets "assets/" tests/test-7.json
python3 build.py
```

Талдағыш бір дұрыс жауапты, бірнеше жауапты және сәйкестендіру сұрақтарын, оқу
мәтіндері мен суреттерді өзі ажыратады. Тек әріп қалың болып, жауап мәтіні қалың
болмаса, ол нұсқа дұрыс жауап деп саналмайды.

### tests/*.json пішімі

```jsonc
{ "slug": "test7", "title": "7-тест",
  "questions": [
    { "n": 1, "type": "single",            // single | multi | match
      "q": "Сұрақ мәтіні",
      "options": [ { "id": "A", "text": "Нұсқа" } ],
      "answer": "A",                       // single: бір әріп
                                           // multi:  ["B","C","D"]
                                           // match:  жоқ, орнына items
      "items": [ { "text": "Липаза", "answer": "B" } ],   // тек match үшін
      "points": 1,
      "images": ["assets/test7-1.png"],                   // міндетті емес
      "context": { "title": "…", "body": "…",             // міндетті емес
                   "images": ["assets/test7-2.png"] } }
  ] }
```

## Бағалау

- **Бір дұрыс жауап** — 1 балл
- **Сәйкестендіру** — әр жұп бөлек, әрқайсысы 1 балл (барлығы 2)
- **Бірнеше дұрыс жауап** — ҰБТ ережесімен: барлық дұрыс нұсқа белгіленсе 2 балл,
  дәл біреуі жетіспесе 1 балл, одан аз, артық немесе қате нұсқа болса 0 балл

## Жариялау

Сайт `main` бұтағының түбірінен тікелей беріледі: **Settings → Pages → Source →
`Deploy from a branch`**, Branch `main`, папка `/ (root)`. `main`-ге әр пуштан
кейін GitHub сайтты өзі қайта құрастырады.

`.nojekyll` файлы Jekyll өңдеуін өшіреді, сондықтан `index.html` сол күйі беріледі.

`.github/workflows/build-check.yml` жариялауға қатыспайды — ол тек құрастырылған
файлдардың `tests/` ішіндегі деректермен сәйкестігін тексереді.

Жергілікті қарау үшін `index.html` файлын браузерде ашсаңыз жеткілікті —
серверсіз де жұмыс істейді.
