# Биология — ҰБТ үлгісіндегі тест

`Биология тест 2.docx` файлынан құрылған, браузерде жұмыс істейтін тест.
Сервер де, орнату да қажет емес — бір HTML файл.

**Ашу:** https://240204016-art.github.io/ai-finance-course/

## Тест құрылымы

| Сұрақтар | Түрі | Балл |
| --- | --- | --- |
| 1–30 | Бір дұрыс жауап | 1 |
| 31–35 | Сәйкестендіру — әр жұп бөлек бағаланады | 2 |
| 36–40 | Бірнеше дұрыс жауап | 2 |

Барлығы **40 сұрақ, 50 балл**. 26–30 сұрақтарға «Есту мүшесі – құлақ» мәтіні қоса шығады.

Бірнеше дұрыс жауапты сұрақтар ҰБТ ережесімен бағаланады: барлық дұрыс нұсқа
белгіленсе — 2 балл, дәл біреуі жетіспесе — 1 балл, одан аз, артық немесе қате
нұсқа болса — 0 балл.

## Мүмкіндіктері

- Таймер: 40 / 60 / 90 минут немесе шектеусіз
- Сұрақтар мен жауап нұсқаларын араластыру
- Емтихан және жаттығу (дұрыс жауап бірден көрінеді) режимдері
- Сұрақтар картасы, «белгілеп қою», пернетақта жылдамдатқыштары
- Аяқтағаннан кейін: балл, бөлімдер бойынша талдау, әр сұрақтың шолуы, «тек қателер» сүзгісі
- Жартылай тапсырылған тест браузерде сақталады және жалғасады

## Файлдар

| Файл | Мазмұны |
| --- | --- |
| `questions.json` | Сұрақтар базасы — жалғыз дереккөз |
| `src/page.html` | Беттің шаблоны (мәнер, логика), деректер орны `__DATA__` |
| `build.py` | Шаблон мен деректерден екі нұсқаны құрастырады |
| `index.html` | Толық HTML құжат — GitHub Pages жариялайтын нұсқа |
| `artifact.html` | Тек бет мазмұны — Claude артефактісі үшін |

`index.html` пен `artifact.html` — құрастырылатын файлдар, оларды қолмен түзетудің
қажеті жоқ.

## Өзгерту

Сұрақ мәтінін, нұсқаларды немесе дұрыс жауапты `questions.json` ішінен түзетіңіз,
сосын:

```sh
python3 build.py
```

Беттің көрінісін не логикасын өзгерту үшін `src/page.html` файлын түзетіп, сол
команданы қайталаңыз.

### questions.json пішімі

```jsonc
{ "n": 1, "type": "single",            // single | multi | match
  "q": "Сұрақ мәтіні",
  "options": [ { "id": "A", "text": "Нұсқа" }, … ],
  "answer": "A",                       // single: бір әріп
                                       // multi:  ["B","C","D"]
                                       // match:  жоқ, орнына items
  "items": [ { "text": "Липаза", "answer": "B" } ],   // тек match үшін
  "points": 1,
  "context": { "title": "…", "body": "…" } }          // қосымша мәтін, міндетті емес
```

## Жариялау

`main` бұтағына әр пуш сайын `.github/workflows/pages.yml` тестті қайта құрастырып,
GitHub Pages-ке жібереді. Бірінші іске қосылғанда Pages автоматты қосылады
(`actions/configure-pages`), қосымша баптау қажет емес.

Жергілікті қарау үшін `index.html` файлын браузерде ашсаңыз жеткілікті.
