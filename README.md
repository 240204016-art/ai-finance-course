# Биология — ҰБТ үлгісіндегі тест

`Биология тест 2.docx` файлынан құрылған, браузерде жұмыс істейтін тест.

- **40 сұрақ / 50 балл**
  - 1–30 — бір дұрыс жауап (1 балл)
  - 31–35 — сәйкестендіру (2 балл)
  - 36–40 — бірнеше дұрыс жауап (2 балл)
- Таймер (40 / 60 / 90 мин немесе шектеусіз), сұрақтар мен нұсқаларды араластыру
- Емтихан және жаттығу (жауап бірден көрінеді) режимдері
- Сұрақтар картасы, белгілеп қою, аяқтағаннан кейін әр сұрақтың толық талдауы
- Нәтиже тек браузерде сақталады (`localStorage`), сервер қажет емес

## Файлдар

| Файл | Мазмұны |
| --- | --- |
| `index.html` | Толық тест — сыртқы тәуелділігі жоқ, бір файл |
| `questions.json` | Сұрақтар базасы (`index.html` ішіне де енгізілген) |

## Қолдану

`index.html` файлын браузерде ашу жеткілікті. GitHub Pages арқылы жариялау үшін
репозиторий параметрлерінде Pages бөлімін қосып, түбірлік каталогты көрсетіңіз.

Сұрақ мәтінін немесе жауапты өзгерту үшін `questions.json` файлын түзетіп,
сол өзгерісті `index.html` ішіндегі `<script id="quiz-data">` блогына көшіріңіз.
