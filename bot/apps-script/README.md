# Ботты Google Apps Script-ке орнату (тегін)

Бот Telegram-да жұмыс істейді, ал оның программасы Google-да тұрады.
Сервер де, ақы да, карта да керек емес. Тапсырыстар Google кестеге жазылады.

## Алдын ала дайындаңыз

1. **Токен.** Telegram → `@BotFather` → `/newbot` → ат пен username беріңіз → ұзын кодты (токен) сақтап қойыңыз.
2. **Өз ID-іңіз.** Telegram → `@userinfobot` → Start → `Id` деген санды жазып алыңыз.
3. **Жабық арна.** Telegram → Жаңа арна → түрі «Жеке». Ботты әзірге қоспаңыз.

## Орнату

1. [sheets.new](https://sheets.new) ашыңыз — жаңа Google кесте жасалады. Атын «Курс тапсырыстары» деп қойыңыз.
2. Мәзірден **Кеңейтімдер → Apps Script** (Extensions → Apps Script) басыңыз.
3. Ашылған беттегі кодты түгел өшіріп, орнына [`Code.gs`](Code.gs) файлының ішін түгел көшіріп қойыңыз.
4. Жоғарғы жақтағы `CONFIG` бөлімін толтырыңыз:
   - `BOT_TOKEN: "7123456789:AAH..."` — токен;
   - `ADMIN_IDS: [123456789]` — өз ID-іңіз (тырнақшасыз, тік жақшаның ішінде);
   - `PRODUCT_NAME`, `PRICE`, `KASPI_PHONE`, `KASPI_NAME` — курс пен Kaspi деректері;
   - `SECRET: "kezkelgenuzynsoz2026"` — өзіңіз ойлап тапқан ұзын сөз (тек латын әріптері мен цифрлар).
5. 💾 **Сақтау** басыңыз.
6. Оң жақ жоғарыда **Deploy → New deployment**:
   - тісті дөңгелек ⚙ → **Web app**;
   - Execute as: **Me**;
   - Who has access: **Anyone**;
   - **Deploy** басыңыз. Google рұқсат сұрайды — өз аккаунтыңызды таңдап, «Advanced → Go to … (unsafe) → Allow» басыңыз (бұл өз скриптіңіз, қауіпсіз).
7. Шыққан **Web app URL** сілтемесін (`https://script.google.com/macros/s/.../exec`) көшіріп, `CONFIG` ішіндегі `WEBAPP_URL: ""` тырнақшасының ішіне қойыңыз. 💾 Сақтаңыз.
8. Жоғарыдағы функция тізімінен **`setWebhook`** таңдап, ▶ **Run** басыңыз. Төменде «Дайын. Бот: @…» шықса — бәрі қосылды.
9. Telegram-да ботыңызға `/start` жазыңыз. Жауап берсе, жұмыс істеп тұр.

## Арнаны қосу

1. Арна → Әкімшілер → Әкімші қосу → ботыңыз. «Сілтеме арқылы шақыру» рұқсаты қосулы болсын.
2. Бот сізге `CHANNEL_ID: -100…` деп жазады.
3. Сол санды `CONFIG` ішіне жазыңыз: `CHANNEL_ID: "-1001234567890"`. 💾 Сақтаңыз.
4. **Deploy → Manage deployments → ✏ (қарындаш) → Version: New version → Deploy.**

> **Маңызды.** Кодты не `CONFIG`-ті әр өзгерткен сайын 4-қадамды қайталаңыз
> (Manage deployments → ✏ → New version → Deploy). Әйтпесе бот ескі нұсқамен
> жұмыс істей береді. «New deployment» баспаңыз — сілтеме өзгеріп кетеді.

## Тексеру

Басқа аккаунттан ботқа `/start` жазып, төлеу батырмасын басыңыз, кез келген суретті
«чек» ретінде жіберіңіз. Сізге «✅ Растау / ❌ Қабылдамау» батырмалары бар хабар келеді.
«Растау» бассаңыз, ол адамға арнаға бір реттік сілтеме барады, ал кестедегі
«Тапсырыстар» бетінде оның жолы `paid` болады.

## Бірдеңе істемесе

- **Бот жауап бермейді.** Apps Script-те `checkWebhook` функциясын іске қосыңыз — `last_error_message` жолында себебі жазылады. Жиі себеп: «Who has access» **Anyone** емес, немесе `WEBAPP_URL` қате көшірілген.
- **«Растау» басқанда қате шығады.** Бот арнада әкімші емес немесе `CHANNEL_ID` қате.
- **Өзгеріс көрінбейді.** Жаңа нұсқа шығармағансыз (жоғарыдағы «Маңызды» бөлімін қараңыз).

## Командалар

| Команда | Кім | Не істейді |
| --- | --- | --- |
| `/start` | сатып алушы | сатып алуды бастайды |
| `/id` | бәрі | Telegram ID көрсетеді |
| `/stats` | әкімші | неше төлем, неше чек тексеруде, түсім |

Промокод: `PROMOS: { "START": 7900 }` — код пен жаңа баға.
