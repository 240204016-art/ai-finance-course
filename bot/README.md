# Лендинг + бот продаж

Продающая страница (`landing/`) и Telegram-бот (`bot/`), который принимает
оплату через Kaspi по чеку и выдаёт одноразовую ссылку в закрытый канал.

```
лендинг → кнопка «Осы пакетті аламын» → бот → реквизиты Kaspi
→ покупатель присылает чек → вы нажимаете «Растау» → бот шлёт ссылку в канал
```

## 1. Лендинг

Все тексты, цена, таймер и FAQ лежат в `landing/config.js` — правьте только его.
Страница откроется по адресу
https://240204016-art.github.io/ai-finance-course/landing/ после слияния ветки в `main`.

- `botUsername` — имя бота без `@`.
- `video` — ссылка на YouTube или путь к mp4.
- `deadline` — реальная дата конца акции; если пусто, работает `timerMinutes`.
- `landing/oferta.html` — заготовка оферты: заполните жёлтые места своими данными.

## 2. Бот

1. В [@BotFather](https://t.me/BotFather): `/newbot` → получите токен.
2. Скопируйте `bot/.env.example` в `bot/.env`, впишите `BOT_TOKEN`, реквизиты Kaspi, цену.
3. Запустите `python3 bot/bot.py` (нужен только Python 3.9+, библиотек нет).
   Без `ADMIN_IDS` бот не стартует: временно впишите любое число, напишите боту `/id`,
   подставьте свой настоящий ID и перезапустите.
4. Создайте закрытый канал и добавьте бота администратором с правом
   «Приглашать по ссылке». Бот пришлёт вам `CHANNEL_ID=-100…` — впишите его в `.env`
   и перезапустите.

Проверка: откройте `https://t.me/ВАШ_БОТ?start=buy` со второго аккаунта и пройдите путь до конца.

| Команда | Кто | Что делает |
| --- | --- | --- |
| `/start` | покупатель | начало покупки; `/start promo_КОД` — с промокодом |
| `/id` | все | показывает Telegram ID |
| `/stats` | админ | сколько оплат, чеков на проверке, выручка |

Промокоды задаются в `.env`: `PROMOS=START:7900,DOS:8900` (код → цена). На лендинге
код только передаётся боту, поэтому подсмотреть список кодов в коде страницы нельзя.

## 3. Хостинг

**Бесплатный вариант:** бот на Google Apps Script — [apps-script/README.md](apps-script/README.md)
(сервер и карта не нужны, заказы пишутся в Google-таблицу). Ниже — вариант с Python.

Бот должен работать постоянно. Подойдёт любой сервер с Python: VPS, Railway, Render.
Команда запуска — `python3 bot/bot.py`, значения из `.env` задайте переменными окружения.

Заказы хранятся в SQLite-файле `bot/orders.db` (путь меняется через `DB_PATH`). На Railway и
подобных платформах диск стирается при каждом деплое — подключите постоянный том (volume) и
укажите `DB_PATH` внутри него, иначе статусы заказов потеряются.
